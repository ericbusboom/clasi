# Add Philosophy Section to README

Add a "Philosophy" section to `README.md` with a short quote from Ursula K. Le Guin about the value of process and craft. The section should appear after the introduction and before the installation instructions.

## Description

The README currently jumps from the project introduction straight into installation. A brief "Philosophy" section — anchored by a Le Guin quote about process and craft — would give readers a sense of the values behind the tool before they install it.

Suggested quote (from *The Wave in the Mind*, 2004):

> "It is good to have an end to journey toward; but it is the journey that matters, in the end."

The section should be short: the quote, one or two sentences of framing, and nothing more.
