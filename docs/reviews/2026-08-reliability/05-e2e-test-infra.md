# Review: E2E + test infrastructure (agent report, verbatim)

## How the E2E works today

**Mechanism** (all under `tests/e2e/`):

1. **Build & launch — `start.sh`.** Builds a wheel from the local tree (`uv build --wheel`, start.sh:169-175; or `CLASI_SOURCE=<tag>` pins a release), builds the image (`Dockerfile`: python:3.14-slim + Node 22 + **unpinned** `npm install -g @anthropic-ai/claude-code` at Dockerfile:22 + the wheel), probes bind-mount host-visibility (start.sh:159-166, with a `~/.clasi/e2e-project` symlink fallback for the OrbStack VM-local-mount failure), wipes `e2e-project/` via `guarded_wipe` unless `--resume`, then `docker run -d --name clasi-e2e` with `/project` bind-mounted. Auth: `--auth=openrouter` (default; `OPENROUTER_API_KEY` → `ANTHROPIC_API_KEY` + `ANTHROPIC_BASE_URL=https://openrouter.ai/api/v1`, model default `anthropic/claude-opus-4.8`) or `--auth=subscription` (read-only staged copy of the host's Keychain OAuth creds, start.sh:96-110, 260-269). Readiness = "tmux session exists" only (start.sh:284-298).
2. **Container init — `entrypoint.sh`.** Fresh: `clasi init --claude --yes` → `git init` → copy `guessing-game-spec.md` to `/project/docs/` → pre-accept trust → launch a keep-alive interactive `claude --dangerously-skip-permissions` in tmux (with blind `sleep 3; send-keys Down/Enter` dialog handling, entrypoint.sh:86-93) → `while true; do sleep 60; done` (line 108). `--resume`/`E2E_RESUME=1` skips init.
3. **The driver.** No script drives the agent. A **host Claude Code session ("tester")** reads `AGENTS.md` (behavior playbook) + `script.md` (7-milestone timeline: Mode-D bootstrap; sprint 1 with corrections then Mode A; OOP-on-master + issues + a reversal; sprint 2 Mode B + OOP-during; bug report + sprint 3 Mode C left open + OOP-open; sprint 4 Mode A + OOP-master; grade) + `stakeholder-persona.md` (phrasing register mined from Eric's real transcripts, incl. speech-to-text garbling), and fires per-milestone `docker exec clasi-e2e claude -p --dangerously-skip-permissions --output-format text --max-turns <N> "<prompt>"` (AGENTS.md:140-156). The in-container "subject" is the CLASI team-lead under test.
4. **Success checks.** `validate.sh` — 29 mechanical checks via `docker exec` (sprint/ticket/archive artifacts, product behavior via `python -m guessing_game`, four exact spec strings grepped from source, git hygiene, all 3 OOP edits survived); exit 1 on any FAIL. Plus `rubric.md`, walked manually by the tester: Category A process-integrity (no lead-written code, no skipped gates, no fabricated completion, reversal retired via `move_issue_to_done`), B frontmatter/lifecycle, C docs, D = validate.sh. Any Category-A FAIL fails the run.
5. **Duration & residue.** 20–55 min per the issue file; the July fixture shows one sprint-execute dispatch alone at 1776 s. A run leaves the full project on the host at `tests/e2e/e2e-project/` (currently 27 MB of stale July-17/18 run: `.venv` 9.6 MB, `.git`, and — importantly — `.clasi/log/` 15 MB containing `hooks.log`, `mcp-server.log` with per-call CALL/OK/FAIL lines and a raw-RPC tap, and 32+ per-dispatch transcript files with `duration_seconds` frontmatter). **Not a repo-hygiene problem: `git ls-files tests/e2e` tracks exactly 13 harness files; `e2e-project/`, wheels, and `.creds-stage/` are gitignored, and `.dockerignore` keeps the fixture out of the build context; `norecursedirs` (pyproject.toml:46) keeps pytest out of it.**
6. **Current blocker.** The default openrouter path cannot run at all: the `claude` CLI rejects every model through the base-URL redirect (issue on file); subscription auth is the working path.

## Instrumentation plan

Much already exists in-container and lands on the host bind mount: `hooks.log` (one line per hook decision with exit code, reason, agent tier, session id — `_log_hook_event`, `src/clasi/hook_handlers.py:299-368`), `mcp-server.log` (per-call `[agent] CALL name(args)` / `OK`/`FAIL` + schema dump + raw JSON-RPC tap — `_logged_call_tool`, `src/clasi/mcp_server.py:237-257`), and per-dispatch transcripts with `duration_seconds` (`src/clasi/dispatch_log.py` → `.clasi/log/NNN-*.md`). Gaps: host-side capture, durations, phase timing, aggregation. Ordered:

1. **Run directory + captured subject sessions** — new `tests/e2e/run.sh` wrapper the tester must use instead of raw `docker exec` (mandate in `AGENTS.md`). Each call writes `e2e-project/.e2e-runs/<run-id>/<NN>-<slug>/{prompt.txt, output.jsonl, exit-code, duration}`; switch to `--output-format stream-json --verbose` so tool calls and turn counts are in the record. run-id minted by start.sh.
2. **Preflight probe** — in `start.sh` after tmux wait: `docker exec clasi-e2e claude -p --max-turns 1 "Reply READY"` and `docker exec clasi-e2e clasi --version`; write to `.e2e-runs/<run-id>/preflight.txt`; abort on failure.
3. **MCP call durations + machine-readable trace** — in `_logged_call_tool` (`src/clasi/mcp_server.py:237-257`): wrap the await in `time.monotonic()`, log `OK name (NNNms)`, and append one JSON line per call to `.clasi/log/mcp-calls.jsonl` (`ts, agent, tool, args, ok, ms, result_len`).
4. **Sprint-phase timing** — add a `phase_transitions` table (`sprint_id, from_phase, to_phase, at`) to `_SCHEMA` in `src/clasi/state_db_class.py:64-113`, written inside `advance_phase` (currently only `sprints.phase`/`updated_at` — no history). Expose via `detail_sprint`/`get_sprint_status`.
5. **Deny-path payload capture** — in `_log_hook_event` (`src/clasi/hook_handlers.py:299-368`): when `exit_code == 2` (and on guard-internal exceptions), dump the full hook payload to `.clasi/log/denied/<ts>-<hook>.json` (dir already auto-gitignores via `_ensure_log_gitignore`, hook_handlers.py:283). Builds the real-payload corpus guard tests need.
6. **Container + session artifact collection** — `start.sh`: record `claude --version`, `clasi --version`, image digest into run dir. `stop.sh`: before `docker rm`, `docker logs clasi-e2e > .e2e-runs/<run-id>/container.log` and `docker cp` `/home/agent/.claude/projects` into the run dir.
7. **Single run report** — new `tests/e2e/report.sh` (validate.sh stays a pure checker): assembles `run-report.md` from (a) validate.sh output, (b) run.sh per-milestone durations/exit codes, (c) phase timings, (d) mcp-calls.jsonl top-N slow + all FAILs, (e) hooks.log deny count + reasons histogram, (f) dispatch inventory from `.clasi/log/NNN-*.md` frontmatter, (g) a scan of `mcp-server.log` for `input_value={}` validation errors (the empty-args bug signature). Tester appends rubric grades at Milestone 6.
8. **Coverage harness** (already specced in the issue file — coordinate, don't duplicate): editable/local install under `COVERAGE_PROCESS_START` in `Dockerfile`/`entrypoint.sh`, `.coveragerc` with `parallel = true`, combine step in `report.sh`, `[tool.coverage.paths]` remap in `pyproject.toml`, drop the stale `role_guard.py` omit (pyproject.toml:54 — file no longer exists).

## Failure modes the E2E does not reproduce (+ minimal scenarios)

1. **Guards failing open**: `tests/e2e/probe-guards.sh`, run between milestones — `docker exec` replays of captured payloads from the deny corpus: tier-0 Edit to a source path with no in-progress ticket → assert exit 2; deliberately malformed payload → assert deny, not silent allow.
2. **Stale MCP runtime**: mid-run, `docker exec pip install` a rebuilt wheel with a bumped version while the subject's MCP server is alive; next subject turn must surface the stale-guard rather than silently running old code.
3. **Subagent background-test stall**: one scripted sprint whose ticket text tempts a background test run; assert from dispatch log + ticket frontmatter that the programmer terminated and the team-lead completed `move_ticket_to_done`. Add as a rubric-B item.
4. **MCP server unavailable**: container variant with `.mcp.json` pointing at a broken command; one `claude -p` turn; assert the subject stops with the canonical message and creates no manual artifacts.
5. **`close_sprint` tag-push** — currently written off as "expected noise" (AGENTS.md:311-319): `git init --bare /home/agent/origin.git` + `git remote add origin` in `entrypoint.sh`; the push becomes a validate.sh check.
6. **OOP file-vs-DB override semantics**: tester creates `.clasi/oop` mid-run, requests a change, asserts gates skip and report the source correctly; then removes it and asserts gates re-engage.

## Top structural recommendations

1. **Make every run self-recording** (plan items 1, 2, 6, 7): run.sh wrapper + `.e2e-runs/<run-id>/` + `run-report.md`. Prerequisite for using the e2e to validate the reliability worktree.
2. **Unblock driving first**: pin `@anthropic-ai/claude-code`, add the preflight probe, default `--auth=subscription` until the OpenRouter model-gate issue is resolved.
3. **Activate the fast/slow split and unweld coverage from addopts** (`pyproject.toml:47`): mark system/integration/real-git tests slow, add `just test` / `just test-all`. Turns the 6–10 min default into a sub-minute dev loop with zero test deletion.
4. **Thin the duplicated tiers with the e2e as the acceptance backstop**: platform tests duplicated across tiers (~117), status tested at four layers, `tests/system/test_artifact_tools.py` at 96 — keep unit comprehensive, prune the rest per the issue's developer-driven flow.
5. **Make `tests/` mean "pytest collects this"**: delete `tests/dev` and `tests/proj`, relocate `tests/asr`; keep `tests/e2e/e2e-project` transient-and-gitignored as it already correctly is.
